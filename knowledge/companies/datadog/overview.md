# Datadog Research

- **Industry**: Observability, Monitoring, Cloud Infrastructure
- **Description**: Datadog provides monitoring and analytics for cloud-scale applications, offering a unified platform for infrastructure monitoring, APM, log management, and security observability.
- **Culture**: Engineering-driven culture that values technical depth, ownership, and data-informed decision making.
- **Tech Stack**: Go, Python, Kafka, Kubernetes, eBPF, Cassandra, Redis
- **Strategic Angle**: Unified observability platform combining metrics, traces, and logs into a single pane of glass.

## Key Challenges
- Scaling infrastructure to process trillions of events per day
- Real-time anomaly detection across massive distributed systems
- Maintaining low query latency on petabytes of observability data

## Interview Tips
- Emphasize experience with distributed systems, large-scale data pipelines
- Show deep understanding of observability concepts (metrics, traces, logs)
- Highlight Go or Python backend experience
- Be ready to discuss system design for high-throughput data ingestion
